# Code Notes

**Code Notes** — расширение для Visual Studio Code, предназначенное для создания и управления заметками к исходному коду.

Расширение позволяет сохранять пояснения к отдельным фрагментам кода, не изменяя исходные файлы проекта.

## Возможности

- Создание заметок к выделенным фрагментам кода.
- Сохранение заметок в отдельный файл `.code-notes.json`.
- Просмотр списка сохранённых заметок.
- Удаление ненужных заметок.
- Хранение заметок отдельно от исходного кода.

## Используемые технологии

- Visual Studio Code API
- TypeScript
- Node.js
- npm
- JSON

## Установка и запуск

1. Клонируйте репозиторий:

   `git clone https://github.com/Varya75/code-notes-vscode.git`

2. Перейдите в папку проекта:

   `cd code-notes-vscode`

3. Установите зависимости:

   `npm install`

4. Скомпилируйте проект:

   `npm run compile`

5. Откройте проект в Visual Studio Code и запустите расширение через Run and Debug.

## Использование

Откройте палитру команд сочетанием `Ctrl + Shift + P`.

Доступные команды:

- Создать заметку к коду.
- Показать заметки.
- Удалить заметку.

## Хранение данных

Заметки сохраняются в файле `.code-notes.json` в корневой папке открытого проекта.

Исходные файлы программы не изменяются.
